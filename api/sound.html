音效 / BGM

play_sound PLAYSOUND
play_sound(filename: str, repeat: int = 1) -> None

播放音效文件（PLAYSOUND 指令的 Python 封装）。

从 ``sound/`` 目录加载并播放指定的音效文件。 引擎会自动寻找一个空闲的音效通道进行播放。

Parameters ---------- filename : str 音效文件名（例如 ``"se_click.wav"``）。 repeat : int, optional 重复播放次数（默认为 ``1``）。 使用 ``-1`` 表示无限循环播放。

Returns ------- None

参数

filename必需str

音效文件名（例如 ``"se_click.wav"``）。

repeatint= 1

重复播放次数（默认为 ``1``）。 使用 ``-1`` 表示无限循环播放。

stop_sound STOPSOUND
stop_sound() -> None

停止所有正在播放的音效（STOPSOUND 指令的 Python 封装）。

立即终止所有音效通道中的播放，不影响背景音乐（BGM）。

Returns ------- None

play_bgm PLAYBGM
play_bgm(filename: str) -> None

播放背景音乐（PLAYBGM 指令的 Python 封装）。

从 ``sound/`` 目录加载并播放指定的音乐文件，默认无限循环。 如果当前已有 BGM 正在播放，会先停止旧的 BGM 再播放新的。

Parameters ---------- filename : str 音乐文件名（例如 ``"bgm_title.mp3"``）。

Returns ------- None

参数

filename必需str

音乐文件名（例如 ``"bgm_title.mp3"``）。

stop_bgm STOPBGM

停止背景音乐（STOPBGM 指令的 Python 封装）。

终止当前播放的背景音乐。

Returns ------- None

set_sound_volume SETSOUNDVOLUME
set_sound_volume(volume: int) -> None

设置音效音量（SETSOUNDVOLUME 指令的 Python 封装）。

调整所有音效通道的音量大小。

Parameters ---------- volume : int 音量值，范围 ``0`` ~ ``100``（``0`` 为静音，``100`` 为最大音量）。 超出范围的值会被自动截断到 ``[0, 100]`` 区间。

Returns ------- None

参数

volume必需int

音量值，范围 ``0`` ~ ``100``（``0`` 为静音，``100`` 为最大音量）。 超出范围的值会被自动截断到 ``[0, 100]`` 区间。
