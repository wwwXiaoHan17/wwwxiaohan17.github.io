事件注册

event
event(name: Optional[str] = None)

注册函数为 Emuera 事件处理器的装饰器。

被装饰的函数会在引擎调用对应名称的事件时被触发。 若省略 *name*，则使用函数的 ``__name__`` 作为事件名。

Parameters ---------- name : str, optional 事件名称。省略时使用函数名的 snake_case 形式。

Returns ------- callable 装饰器函数。

Example -------

>>> @event("system_title")

... def my_title():

... pyera.clear_display()

...     pyera.print_line("My Game")

参数

nameOptional[str]= None

事件名称。省略时使用函数名的 snake_case 形式。 装饰器函数。

get_registered_events
get_registered_events() -> Dict[str, Callable[Ellipsis, Any]]

获取所有通过 :func:`event` 装饰器注册的事件处理函数。

Returns ------- dict[str, callable] 事件名称到处理函数的映射字典副本。

register_events_into
register_events_into(globals_dict: Dict[str, Any]) -> None

将已注册的事件注入到模块的全局命名空间中。

在以编程方式动态加载模块时非常有用，可确保事件处理器在目标模块中可见。

Parameters ---------- globals_dict : dict 目标模块的 ``globals()`` 字典。

Returns ------- None

参数

globals_dict必需Dict[str, Any]

目标模块的 ``globals()`` 字典。

decorator
decorator(func: Callable[Ellipsis, Any]) -> Callable[Ellipsis, Any]

内部装饰器函数，将目标函数注册到事件字典中。

Parameters ---------- func : callable 被装饰的目标函数。

Returns ------- callable 原函数对象（未做包装，便于调试和类型检查）。

参数

func必需Callable[Ellipsis, Any]

被装饰的目标函数。 原函数对象（未做包装，便于调试和类型检查）。
