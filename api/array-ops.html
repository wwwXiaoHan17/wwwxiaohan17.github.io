var_set VARSET
var_set(name: str, value: int, start: int = 0, end: int = -1) -> None

批量设置整数型数组变量的值（VARSET 指令的 Python 封装）。

将指定数组变量从 *start* 到 *end*（不含）的所有元素设置为 *value*。

Parameters ---------- name : str 目标变量名（例如 ``"flag"``、``"item"``）。 value : int 要填充的整数值。 start : int, optional 起始索引（默认为 ``0``）。 end : int, optional 结束索引（``-1`` 表示数组末尾）。

Returns ------- None

参数

name必需str

目标变量名（例如 ``"flag"``、``"item"``）。

value必需int

要填充的整数值。

startint= 0

起始索引（默认为 ``0``）。

endint= -1

结束索引（``-1`` 表示数组末尾）。
