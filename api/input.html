wait_input INPUT
wait_input() -> int

等待玩家输入整数（INPUT 指令的 Python 封装）。

阻塞当前线程，直到玩家在输入框中输入一个整数并确认。 输入值会被引擎存入 ``RESULT`` 变量。

Returns ------- int 玩家输入的整数值；出错或 stub 模式下返回 ``0``。

tinput TINPUT
tinput(timeout: int, default_val: int = 0, one_input: bool = False, display_time: bool = True) -> int

带超时的整数输入（TINPUT 指令的 Python 封装）。

在指定时间内等待玩家输入整数，超时后自动返回默认值。

Parameters ---------- timeout : int 超时时间，单位毫秒。 default_val : int, optional 超时后返回的默认值（默认为 ``0``）。 one_input : bool, optional 若 ``True`` 则只接受单个数字输入（相当于 ONETINPUT）。 display_time : bool, optional 是否在屏幕上显示倒计时（默认为 ``True``）。

Returns ------- int 玩家输入的整数值，或超时后的 *default_val*。

参数

timeout必需int

超时时间，单位毫秒。

default_valint= 0

超时后返回的默认值（默认为 ``0``）。

one_inputbool= False

若 ``True`` 则只接受单个数字输入（相当于 ONETINPUT）。

display_timebool= True

是否在屏幕上显示倒计时（默认为 ``True``）。 玩家输入的整数值，或超时后的 *default_val*。

等待玩家点击整数型按钮（BINPUT / ONEBINPUT 指令的 Python 封装）。

Returns ------- int 被点击按钮对应的整数值，或 *default_val*。

参数

default_valint= 0

无可用按钮时返回的默认值（默认为 ``0``）。

mousebool= False

是否允许鼠标点击按钮（默认为 ``False``，仅键盘选择）。

one_inputbool= False

若 ``True`` 则只接受单个数字快捷选择（ONEBINPUT 行为）。 被点击按钮对应的整数值，或 *default_val*。

get_key GETKEY
get_key(keycode: int) -> int

检查指定按键是否被按下（GETKEY 指令的 Python 封装）。

检测当前时刻键盘上某个虚拟键码对应的按键是否处于按下状态。

Parameters ---------- keycode : int 虚拟键码（Virtual-Key Code），例如 ``13`` 是回车键，``27`` 是 ESC。

Returns ------- int 按键被按住返回 ``1``，否则返回 ``0``。

参数

keycode必需int

虚拟键码（Virtual-Key Code），例如 ``13`` 是回车键，``27`` 是 ESC。 按键被按住返回 ``1``，否则返回 ``0``。

get_key_triggered GETKEYTRIGGERED
get_key_triggered(keycode: int) -> int

检查指定按键是否被触发（GETKEYTRIGGERED 指令的 Python 封装）。

与 ``get_key`` 的区别在于检测的是"触发"状态（切换位）， 即按键从释放到按下的那次转变。

Parameters ---------- keycode : int 虚拟键码。

Returns ------- int 按键被触发返回 ``1``，否则返回 ``0``。

参数

keycode必需int

虚拟键码。 按键被触发返回 ``1``，否则返回 ``0``。
