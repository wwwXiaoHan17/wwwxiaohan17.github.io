PyeraError
PyeraError

Base exception for all pyera runtime errors.

PyeraApiError
PyeraApiError

Raised when a C# engine API call fails or returns unexpectedly.

PyeraVariableError
PyeraVariableError

Raised when variable access (get/set) fails in the engine.

PyeraNotInitializedError
PyeraNotInitializedError

Raised when pyera_native is not available and an engine call is attempted.

PyeraTypeError
PyeraTypeError

Raised when an argument type does not match the C# API expectation.

PyeraValidationError
PyeraValidationError

Raised when input validation fails before reaching the engine.

Parameters ---------- message : str, optional 异常的主要错误信息（默认为空字符串）。 detail : str, optional 异常的详细补充信息，例如底层堆栈跟踪或调试上下文 （默认为空字符串）。
