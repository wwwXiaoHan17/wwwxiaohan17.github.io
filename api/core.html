enable_trace
enable_trace(enabled: bool = True) -> None

启用或禁用调用追踪。

启用后，所有通过 :func:`call` 发起的 C# API 调用都会被记录到内部缓冲区， 便于调试时分析调用序列。

Parameters ---------- enabled : bool, optional ``True`` 启用追踪（默认），``False`` 禁用。

Returns ------- None

See Also -------- get_trace_log : 获取已记录的追踪日志。 clear_trace_log : 清空追踪缓冲区。

参数

enabledbool= True

``True`` 启用追踪（默认），``False`` 禁用。

get_trace_log
get_trace_log() -> list[str]

返回已累计的调用追踪日志副本。

Returns ------- list[str] 追踪记录字符串列表。

clear_trace_log
clear_trace_log() -> None

清空调用追踪缓冲区。

与 :func:`get_trace_log` 配合使用，可在长时间运行或大量调用后 释放内存并重置追踪状态。

Returns ------- None

See Also -------- get_trace_log : 获取当前缓冲区内容。 enable_trace : 启用或禁用追踪功能。

register_coerce
register_coerce(py_type: type, converter: Callable[[, Any]) -> None

注册自定义类型转换器，用于 Python → C# 的参数传递。

当 ``call()`` 遇到 *py_type* 类型的参数时，会先用 *converter* 转换后再传递给 C# 引擎。

Parameters ---------- py_type : type 要匹配的 Python 类型。 converter : callable 接收一个 Python 对象，返回转换后的值。

Example -------

>>> import numpy as np

>>> register_coerce(np.ndarray, lambda arr: arr.tolist())

参数

py_type必需type

要匹配的 Python 类型。

converter必需Callable[[, Any]

接收一个 Python 对象，返回转换后的值。

call
call(name: str, default: T = _UNSET, required: bool = False, *args) -> T

按名称调用 C# API 方法。

这是 Python 侧与 C# 引擎交互的核心原语。所有其他模块的引擎调用 最终都应通过此函数完成。

Parameters ---------- name : str ``pyera_native`` 模块上的方法名（即 ``PyApi`` 中的 ``public static`` 方法）。 *args : Any 位置参数。列表会被自动强制转换为元组。 default : Any, optional Stub 模式或调用失败时的默认返回值。若未提供且 C# 返回 ``None``， 则返回 ``None``。 required : bool, optional 若为 ``True``，在 stub 模式下会抛出 :class:`PyeraNotInitializedError` 而不是返回 *default*。

Returns ------- Any C# 方法的返回值，或在不可用时的 *default*。

Raises ------ PyeraApiError 若 C# 调用本身抛出了异常。 PyeraNotInitializedError 若 ``required=True`` 且当前处于 stub 模式。

Notes ----- - 本函数在调用 C# 期间持有 Python GIL。若 C# 方法执行时间较长， 会阻塞 Python 的其他线程。 - 建议在主线程中调用所有引擎 API。

参数

name必需str

``pyera_native`` 模块上的方法名（即 ``PyApi`` 中的 ``public static`` 方法）。 位置参数。列表会被自动强制转换为元组。

defaultT= _UNSET

Stub 模式或调用失败时的默认返回值。若未提供且 C# 返回 ``None``， 则返回 ``None``。

requiredbool= False

若为 ``True``，在 stub 模式下会抛出 :class:`PyeraNotInitializedError` 而不是返回 *default*。 C# 方法的返回值，或在不可用时的 *default*。 若 C# 调用本身抛出了异常。 若 ``required=True`` 且当前处于 stub 模式。 会阻塞 Python 的其他线程。

get_var_token
get_var_token(name: str) -> Optional[Any]

根据变量名获取引擎的 VariableToken 对象。

这是访问 Emuera 变量系统的核心原语，用于替代直接调用 ``call("vars.get", ...)`` 的重复代码。

Parameters ---------- name : str 变量名称（大小写不敏感，内部会自动转为小写）。

Returns ------- Any or None 引擎的 VariableToken 对象；若变量不存在或处于 stub 模式返回 ``None``。

Notes ----- 返回的 token 是 C# 对象的 Python 引用。长时间大量持有 token 引用 可能影响 C# 侧的垃圾回收。建议在需要时获取、使用完毕后释放引用。

参数

name必需str

变量名称（大小写不敏感，内部会自动转为小写）。 引擎的 VariableToken 对象；若变量不存在或处于 stub 模式返回 ``None``。

通过 VariableToken 安全读取变量值。

封装了 ``token.Get(*indices)`` 调用，并将底层异常统一转换为 :class:`PyeraVariableError`。

Parameters ---------- token : Any 引擎的 VariableToken 对象（由 :func:`get_var_token` 获取）。 *indices : int 变量下标，支持多维（例如 ``(chara_id, elem)``）。

Returns ------- Any 变量值（整数或字符串，取决于变量类型）。

Raises ------ PyeraVariableError 当底层引擎读取失败时抛出。

参数

token必需Any

引擎的 VariableToken 对象（由 :func:`get_var_token` 获取）。 变量下标，支持多维（例如 ``(chara_id, elem)``）。 变量值（整数或字符串，取决于变量类型）。 当底层引擎读取失败时抛出。

*indicesany
