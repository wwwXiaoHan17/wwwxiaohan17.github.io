Returns ------- int 限制后的值。

form
form(template: str, **kwargs) -> str

轻量级格式化字符串生成器（PRINTFORM 的 Python 替代）。

支持两种占位符语法：

- ``{var}`` / ``{var:03}`` — 花括号占位符，支持 Python 格式规范 - ``%str_var%`` — 百分号占位符（兼容旧版 ERB 风格）

Parameters ---------- template : str 包含占位符的模板字符串。 **kwargs : Any 用于替换占位符的键值对。

Returns ------- str 格式化后的字符串。

Example -------

>>> form("HP: {hp:03}/{maxhp:03} Name: %name%", hp=50, maxhp=100, name="Alice") 'HP: 050/100 Name: Alice'

参数

template必需str

包含占位符的模板字符串。 用于替换占位符的键值对。 格式化后的字符串。

**kwargsany

safe_call
safe_call(func: Callable[Ellipsis, T], default: T = None, log_exc: bool = True, *args) -> T

安全调用函数，异常时返回默认值。

将指定函数以给定参数调用，若函数抛出任何异常则返回 *default* 而不向上传播。

Parameters ---------- func : callable 要调用的目标函数。 *args : Any 传递给 *func* 的位置参数。 default : Any, optional 异常时的回退返回值（默认为 ``None``）。 log_exc : bool, optional 是否在异常时通过 :func:`log_error` 记录错误信息（默认为 ``True``）。

Returns ------- Any *func* 的返回值，或异常时的 *default*。

参数

func必需Callable[Ellipsis, T]

要调用的目标函数。 传递给 *func* 的位置参数。

defaultT= None

异常时的回退返回值（默认为 ``None``）。

log_excbool= True
