CharaVarProxy
CharaVarProxy

角色变量代理，支持 ``chara.variable[index]`` 形式的访问。

Chara
Chara

单个角色数据的代理对象。

通过属性访问器（如 ``chara.abl``、``chara.cflag``）获取 :class:`CharaVarProxy`， 再通过下标索引（如 ``chara.abl[2]``）读写具体的角色变量值。

Parameters ---------- chara_id : int 角色在当前角色列表中的索引（``0`` 通常为主人角色）。

chara
chara(chara_id: int) -> Chara

按列表索引获取角色代理对象。

Parameters ---------- chara_id : int 角色在列表中的索引（``0`` 通常为主人角色）。

Returns ------- Chara 对应索引的角色代理对象。

参数

chara_id必需int

角色在列表中的索引（``0`` 通常为主人角色）。 对应索引的角色代理对象。

chara_from_no
chara_from_no(no: int) -> Optional[Chara]

按 CSV 注册编号查找角色。

遍历角色列表，返回第一个 ``NO`` 等于指定编号的角色。

Parameters ---------- no : int 角色的 CSV 注册编号（CSVNO）。

Returns ------- Chara or None 匹配的角色代理对象；未找到时返回 ``None``。

参数

no必需int

角色的 CSV 注册编号（CSVNO）。 匹配的角色代理对象；未找到时返回 ``None``。

chara_by_name
chara_by_name(name: str) -> Optional[Chara]

Parameters ---------- name : str 要搜索的名称子串。

Returns ------- Chara or None 匹配的角色代理对象；未找到时返回 ``None``。

参数

name必需str

要搜索的名称子串。 匹配的角色代理对象；未找到时返回 ``None``。
