流程控制

begin BEGIN
begin(mode: BeginMode) -> None

切换到指定的游戏模式（BEGIN 指令的 Python 封装）。

该函数会在下一个输入等待点安全地切换游戏模式。 如果当前正处于输入等待状态，则会将模式切换请求入队， 待当前输入处理完毕后再执行切换。

Parameters ---------- mode : BeginMode 目标模式字符串，可选值包括： - ``'title'`` — 标题画面 - ``'shop'`` — 商店 - ``'train'`` — 训练/调教 - ``'aftertrain'`` — 训练结束后 - ``'ablup'`` — 能力升级 - ``'turnend'`` — 回合结束 - ``'first'`` — 首次启动

Returns ------- None

See Also -------- begin_force : 强制切换模式，不等待输入点。 force_begin : 立即切换模式并执行 BEGIN。

参数

mode必需BeginMode

目标模式字符串，可选值包括： - ``'title'`` — 标题画面 - ``'shop'`` — 商店 - ``'train'`` — 训练/调教 - ``'aftertrain'`` — 训练结束后 - ``'ablup'`` — 能力升级 - ``'turnend'`` — 回合结束 - ``'first'`` — 首次启动

begin_force BEGIN
begin_force(mode: BeginMode) -> None

强制切换到指定游戏模式（BEGIN 指令的强制版）。

与 ``begin`` 不同，此函数会强制中断当前流程并立即切换模式， 不会等待输入等待点。

Parameters ---------- mode : BeginMode 目标模式字符串，取值与 ``begin`` 相同。

Returns ------- None

参数

mode必需BeginMode

目标模式字符串，取值与 ``begin`` 相同。

call CALL
call(func_name: str) -> bool

调用指定的函数（CALL 指令的 Python 封装）。

调用顺序：先尝试调用 Python 侧注册的同名函数， 若未找到则回退到 ERB 脚本中的函数。

Parameters ---------- func_name : str 要调用的函数名称。

Returns ------- bool 如果成功找到并执行了函数则返回 ``True``，否则返回 ``False``。

参数

要调用的函数名称。 如果成功找到并执行了函数则返回 ``True``，否则返回 ``False``。

jump JUMP
jump(func_name: str) -> bool

无条件跳转到指定函数（JUMP 指令的 Python 封装）。

.. note:: 在 Python 模式下，``jump`` 与 ``call`` 的行为差异较小， 因为 Python 函数执行完后自然返回到调用者。 若要模拟 ERB 中 "不返回" 的语义，建议在 ``jump`` 后使用 ``return`` 结束当前函数。

Parameters ---------- func_name : str 目标函数名称。

Returns ------- bool 如果成功找到并执行了函数则返回 ``True``，否则返回 ``False``。

Example -------

>>> def event_title():

... if some_condition:

... jump("event_special_title")

... return # 确保不继续执行后续代码

...     print_line("正常标题")

See Also -------- call : 调用函数并返回。

参数

func_name必需str

目标函数名称。 如果成功找到并执行了函数则返回 ``True``，否则返回 ``False``。

try_call TRYCALL
try_call(func_name: str) -> bool

尝试调用函数，失败时不报错（TRYCALL 指令的 Python 封装）。

当引擎未初始化时（stub 模式且 ``required=True``）会重新抛出 :class:`PyeraNotInitializedError`，以便调用者知晓环境异常。 其他异常（如函数不存在）则静默返回 ``False``。

Parameters ---------- func_name : str 要尝试调用的函数名称。

Returns ------- bool 调用成功返回 ``True``，函数不存在返回 ``False``。

Raises ------ PyeraNotInitializedError 当引擎未初始化时抛出。

参数

func_name必需str

要尝试调用的函数名称。 调用成功返回 ``True``，函数不存在返回 ``False``。 当引擎未初始化时抛出。

try_jump TRYJUMP
try_jump(func_name: str) -> bool

尝试跳转到函数，失败时不报错（TRYJUMP 指令的 Python 封装）。

Parameters ---------- func_name : str 要尝试跳转的目标函数名称。

Returns ------- bool 跳转成功返回 ``True``，函数不存在返回 ``False``。

参数

要尝试跳转的目标函数名称。 跳转成功返回 ``True``，函数不存在返回 ``False``。

try_call TRYCALL
try_call(func_name: str) -> bool

尝试调用函数，失败时不报错（TRYCALL 指令的 Python 封装）。

当引擎未初始化时（stub 模式且 ``required=True``）会重新抛出 :class:`PyeraNotInitializedError`，以便调用者知晓环境异常。 其他异常（如函数不存在）则静默返回 ``False``。

Parameters ---------- func_name : str 要尝试调用的函数名称。

Returns ------- bool 调用成功返回 ``True``，函数不存在返回 ``False``。

Raises ------ PyeraNotInitializedError 当引擎未初始化时抛出。
