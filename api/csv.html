csv_exist EXISTCSV
csv_exist(chara_no: int, sp: bool = False) -> int

检查指定编号的 CSV 角色模板是否存在（EXISTCSV 指令的 Python 封装）。

Parameters ---------- chara_no : int 角色在 CSV 中的编号（CSVNO）。 sp : bool, optional 是否检查 SP 角色模板（默认为 ``False``）。

Returns ------- int 如果模板存在返回 ``1``，否则返回 ``0``。

参数

chara_no必需int

角色在 CSV 中的编号（CSVNO）。

spbool= False

是否检查 SP 角色模板（默认为 ``False``）。 如果模板存在返回 ``1``，否则返回 ``0``。
