print_c PRINTC
print_c(text: str, alignment_right: bool = False) -> None

列对齐打印（PRINTC 指令的 Python 封装）。

将文本输出到按列对齐的网格位置，常用于制作状态面板、物品列表、 角色属性表等需要整齐排版的场景。

列宽和每行列数由引擎配置项 ``printCPerLine`` 决定（可在 ``emuera.config`` 中调整）。当一行内的列数达到上限后， 引擎会自动换行到下一行继续输出。

Parameters ---------- text : str 要输出的文本内容。若文本长度超过列宽，可能会被截断或溢出。 alignment_right : bool, optional 文本在列内的对齐方式。默认为 ``False``（左对齐）； 设为 ``True`` 时文本在列内右对齐。

Returns ------- None

Example -------

>>> # 假设每行显示 3 列

>>> print_c("HP")

>>> print_c("MP")

>>> print_c("SP")

>>> new_line() # 手动换行，开始下一组

>>> print_c("100", alignment_right=True)

>>> print_c("50", alignment_right=True)

>>> print_c("30", alignment_right=True)

See Also -------- print : 普通打印，不进行列对齐。 print_line : 打印并换行。 new_line : 手动插入换行，可与 ``print_c`` 配合控制换行时机。 get_config : 查询 ``printCPerLine`` 等引擎配置。

参数

text必需str

要输出的文本内容。若文本长度超过列宽，可能会被截断或溢出。

alignment_rightbool= False

文本在列内的对齐方式。默认为 ``False``（左对齐）； 设为 ``True`` 时文本在列内右对齐。
