Returns ------- None

参数

enabledbool= True

``True`` 启用日志记录（默认），``False`` 禁用。

log_set_callback
log_set_callback(callback: Optional[Callable[[, None]]) -> None

设置自定义日志回调函数。

当日志启用时，每条日志消息会通过该回调传递。 传入 ``None`` 则恢复默认输出方式。

Parameters ---------- callback : callable or None 接收单个字符串参数的无返回值回调函数。

Returns ------- None

参数

callback必需Optional[Callable[[, None]]

接收单个字符串参数的无返回值回调函数。

get_logs
get_logs() -> list[str]

获取所有已缓冲的日志消息。

Returns ------- list[str] 日志消息字符串列表的副本。

clear_logs
clear_logs() -> None

清空日志缓冲区。

与 :func:`get_logs` 配合使用，可在长时间运行后释放内存并重置日志状态。 此操作不会影响日志的启用/禁用状态。

Returns ------- None

See Also -------- get_logs : 获取当前缓冲区中的所有日志消息。 log : 输出一条普通日志。 log_error : 输出一条错误日志。
