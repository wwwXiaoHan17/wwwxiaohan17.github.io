类型定义

Alignment
Alignment

行对齐方式枚举。

控制文本在显示行中的水平对齐位置。

Members ------- LEFT = 0 左对齐（默认）。 CENTER = 1 居中对齐，常用于标题或居中提示。 RIGHT = 2 右对齐，常用于数值或状态显示。

See Also -------- pyera.alignment : 设置当前对齐方式。 pyera.current_align : 获取当前对齐方式。

FontStyleFlag
FontStyleFlag

字体样式位标志枚举。

通过按位或（``|``）组合多个标志，可同时应用多种样式。

Members ------- REGULAR = 0 常规样式（无特殊效果）。 BOLD = 1 粗体。 ITALIC = 2 斜体。 STRIKEOUT = 4 删除线。 UNDERLINE = 8 下划线。

See Also -------- pyera.font_style : 应用字体样式。 pyera.get_style : 获取当前字体样式。

RedrawMode
RedrawMode

重绘模式枚举。

控制引擎在何时自动刷新屏幕显示内容。

Members ------- NORMAL = 0 不自动重绘，需手动调用 ``refresh()``。 PRINT_AND_FORCE = 1 每次打印后自动重绘（性能开销较大）。 FORCE = 2 强制完整重绘模式。

See Also -------- pyera.redraw : 设置重绘模式。 pyera.current_redraw : 获取当前重绘模式。

SortOrder
SortOrder

数组排序方向枚举。

Members ------- ASCENDING = 0 升序排列（从小到大）。 DESCENDING = 1 降序排列（从大到小）。 UNDEF = 2 未定义/保持原始顺序。

InputType
InputType

输入请求类型枚举。

标识引擎当前等待的输入类别，用于 ``InputRequest`` 的内部处理。

Members ------- ENTER_KEY = 1 等待按下回车键。 ANY_KEY = 2 等待按下任意键。 INT_VALUE = 3 等待输入一个整数值。 STR_VALUE = 4 等待输入一个字符串值。 VOID = 5 无特定输入要求（占位）。 ANY_VALUE = 6 接受任意类型的输入值。 INT_BUTTON = 7 等待点击一个整数按钮。 STR_BUTTON = 8 等待点击一个字符串按钮。 PRIMITIVE_MOUSE_KEY = 11 原始鼠标按键事件。

parse_color
parse_color(value: Union[str, ColorTuple]) -> ColorTuple

将颜色描述符转换为 ``(R, G, B)`` 元组。

支持以下三种格式：

- ``#RRGGBB`` 十六进制字符串（例如 ``"#FF0000"``） - 颜色名称（例如 ``"red"``、``"blue"``） - 已有的 ``(R, G, B)`` 元组

Parameters ---------- value : str or tuple[int, int, int] 颜色描述符。

Returns ------- tuple[int, int, int] 解析后的 ``(R, G, B)`` 元组，每个分量范围 ``0`` ~ ``255``。

Raises ------ ValueError 当 *value* 无法被解析为有效颜色时抛出。

参数

value必需Union[str, ColorTuple]

颜色描述符。 解析后的 ``(R, G, B)`` 元组，每个分量范围 ``0`` ~ ``255``。 当 *value* 无法被解析为有效颜色时抛出。
