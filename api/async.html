ensure_main_loop
ensure_main_loop(awaitable: Optional[Awaitable[Any]] = None) -> None

确保主线程有一个运行中的事件循环，并可选地提交一个协程。

在 Emuera 的事件处理器（如 ``event_shop``）中调用此函数， 可以启动一个后台事件循环来处理异步任务，同时不阻塞引擎的 UI 线程。

Parameters ---------- awaitable : Awaitable, optional 要提交到事件循环的协程或 awaitable 对象。

Example -------

>>> def event_shop():

...     ensure_main_loop(fetch_data())

参数

awaitableOptional[Awaitable[Any]]= None

要提交到事件循环的协程或 awaitable 对象。

run_on_main
run_on_main(func: Callable[Ellipsis, T], *args, **kwargs) -> T

在主线程上执行一个同步函数（用于引擎 API 调用）。

当异步代码需要调用 Emuera 引擎 API 时，必须将调用提交到主线程。 本函数通过 ``loop.call_soon_threadsafe`` 配合 ``asyncio.wrap_future`` 实现安全的跨线程调用。

Parameters ---------- func : callable 要在主线程执行的函数（通常是 ``pyera.xxx`` 引擎 API）。 *args : Any 位置参数。 **kwargs : Any 关键字参数。

Returns ------- Any 函数的返回值。

Raises ------ RuntimeError 若主线程事件循环未初始化。

Example -------

>>> async def show_result():

... await run_on_main(pyera.print_line, "Done!")

...     await run_on_main(pyera.refresh, True)

参数

func必需Callable[Ellipsis, T]

要在主线程执行的函数（通常是 ``pyera.xxx`` 引擎 API）。 位置参数。 关键字参数。 函数的返回值。 若主线程事件循环未初始化。

*argsany
**kwargsany
run_on_main_sync
run_on_main_sync(func: Callable[Ellipsis, T], timeout: float = 30.0, *args, **kwargs) -> T

在主线程上同步执行一个函数（阻塞当前线程直到完成）。

适用于非异步代码中需要将引擎调用提交到主线程的场景。

Parameters ---------- func : callable 要在主线程执行的函数。 *args : Any 位置参数。 timeout : float, optional 等待超时时间（秒），默认 30 秒。 **kwargs : Any 关键字参数。

Returns ------- Any 函数的返回值。

Raises ------ RuntimeError 若主线程事件循环未初始化。 TimeoutError 若超过 *timeout* 仍未完成。

参数

func必需Callable[Ellipsis, T]

要在主线程执行的函数。 位置参数。

timeoutfloat= 30.0

等待超时时间（秒），默认 30 秒。 关键字参数。 函数的返回值。 若主线程事件循环未初始化。 若超过 *timeout* 仍未完成。

*argsany
**kwargsany
