save_data SAVEDATA
save_data(slot: int, description: str = '') -> bool

保存游戏到指定槽位（SAVEDATA 指令的 Python 封装）。

Parameters ---------- slot : int 存档槽位编号（从 ``0`` 开始）。 description : str, optional 存档描述文本（默认为空字符串）。

Returns ------- bool 保存成功返回 ``True``，失败返回 ``False``。

参数

slot必需int

存档槽位编号（从 ``0`` 开始）。

descriptionstr= ''

存档描述文本（默认为空字符串）。 保存成功返回 ``True``，失败返回 ``False``。

check_data CHKDATA
check_data(slot: int) -> int

检查指定槽位的存档状态（CHKDATA 指令的 Python 封装）。

Parameters ---------- slot : int 要检查的存档槽位编号。

Returns ------- int 存档状态码： - ``0`` — 存档正常可读 - ``1`` — 文件不存在 - ``2`` — 游戏标识不匹配（不同游戏） - ``3`` — 版本不匹配 - ``4`` — 其他错误

参数

slot必需int

要检查的存档槽位编号。 存档状态码： - ``0`` — 存档正常可读 - ``1`` — 文件不存在 - ``2`` — 游戏标识不匹配（不同游戏） - ``3`` — 版本不匹配 - ``4`` — 其他错误

参数

save_chara SAVECHARA
save_chara(filename: str, desc: str, *chara_indices) -> None

将指定角色保存到文件（SAVECHARA 指令的 Python 封装）。

Parameters ---------- filename : str 输出文件名（不含路径，保存到游戏根目录）。 desc : str 保存描述文本。 *chara_indices : int 可变参数，要保存的角色在角色列表中的索引。

Returns ------- None

Example -------

>>> save_chara("party.dat", "主力队伍", 0, 1, 2)

参数

filename必需str

输出文件名（不含路径，保存到游戏根目录）。

desc必需str

保存描述文本。 可变参数，要保存的角色在角色列表中的索引。

*chara_indicesany
