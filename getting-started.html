快速开始

从零开始构建你的第一个 Pyera 项目

1

项目结构

在 Emuera 游戏根目录下创建 py/ 文件夹，将 Python 脚本放在其中：

game_root/
  py/
    main.py          # 主入口
    my_module.py     # 可选模块
  csv/
  era/
  emuera.config
2

编写第一个事件

import pyera

def system_title():
    pyera.clear_display()
    pyera.print_line("=== My Game ===")
    pyera.print_button("[0] Start", 0)
    pyera.new_line()
    pyera.print_button("[1] Load", 1)
    pyera.new_line()
    pyera.refresh(True)

def event_first():
    pyera.clear_display()
    pyera.print_line("Welcome!")
    pyera.read_any_key()
    pyera.begin("title")
3

角色数据访问

count = pyera.chara_count()
for i in range(count):
    c = pyera.chara(i)
    pyera.print_line(f"[{i}] {c.name}: ABL[0]={c.abl[0]}")
4

异步与第三方库

import asyncio
from pyera._async_utils import run_on_main, ensure_main_loop

async def fetch_and_display():
    data = await some_async_http_call()
    await run_on_main(pyera.print_line, data["message"])

def event_shop():
    ensure_main_loop(fetch_and_display())
5

调试技巧

  • 设置环境变量 PYERA_DEBUG=1 启用调试输出
  • 使用 pyera.enable_trace(True) 记录 C# 调用序列
  • 使用 pyera.log("message") 输出调试日志
  • stub 模式下可直接运行 pytest 测试

Build your first Pyera project from scratch

1

Project Structure

Debugging Tips

  • Set env var PYERA_DEBUG=1 to enable debug output
  • Use pyera.enable_trace(True) to record C# call sequences
  • Use pyera.log("message") for debug logging
  • Run pytest directly in stub mode
